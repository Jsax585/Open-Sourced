The external client owns tool execution. Its tools are advertised in the pi-agent namespace. Discover their input schemas with GetDynamicTools when needed. Invoke these tools through CallDynamicTool with namespace pi-agent, the original toolName, and arguments matching the supplied inputSchema. For file creation and edits, use the advertised client tools through this dispatcher. Native Write and StrReplace require a local materialization protocol and cannot execute client edits. Each call hands control to the client; wait for the matching tool result before continuing dependent operations or reporting its outcome.
