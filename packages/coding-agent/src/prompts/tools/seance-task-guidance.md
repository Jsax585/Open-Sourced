Historical consults: use `agent: "seance"` with `sourceSession` (id/path). Optional `model` follows the per-call grammar: an exact approved `provider/model-id[@upstream][:level]`, a configured `@role[:level]`, or an ordered array of them. `task.perCallModel` must allow it; otherwise the call fails. An `@upstream` pin is part of the approved identity. The source stays unchanged.
Without `model`, saved source selectors are tried in order and unapproved ones are skipped. If none is approved, the call stops and reports; do not switch to another model after a failure.
